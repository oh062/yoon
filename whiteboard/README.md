# 나의 화이트보드

서버 없이 브라우저만으로 동작하는 개인용 온라인 화이트보드입니다.
아이디어 정리, 브레인스토밍, 수업 필기, 간단한 다이어그램, 메모에 쓸 수 있어요.
휴대폰·태블릿·PC 모두에서 쓸 수 있고, 데이터는 내 기기에만 저장됩니다.

## 1. 기능

- **무한 캔버스**: 화면 이동(빈 곳 드래그·Space+드래그·두 손가락), 확대/축소 10%~500%(휠·핀치·버튼), 100%로 맞추기, 전체 보기
- **점 격자 배경**(켜기/끄기)과 **격자 스냅**
- **선택/이동**: 클릭·영역 선택·Shift+클릭 추가 선택, 손잡이로 크기 조절, 방향키 미세 이동, 복사/붙여넣기/복제, 앞으로·뒤로 보내기
- **펜**: 부드러운 곡선, 12색과 직접 고르기, 굵기 5단계, 형광펜 모드
- **지우개**: 닿은 획(요소) 단위로 지우기
- **도형**: 사각형, 둥근 사각형, 원/타원, 삼각형, 마름모, 직선, 화살표. 테두리 색·채우기(투명 포함)·굵기·실선/점선. Shift를 누르고 그리면 정비율
- **텍스트**: 크기 S/M/L/XL, 색, 굵게, 왼쪽/가운데 정렬, 더블클릭으로 수정
- **포스트잇**: 6가지 색, 글이 길면 글자 크기 자동 축소, 그림자와 약간 기울어진 모양
- **연결선**: 도형·포스트잇·텍스트를 이으면 요소를 옮겨도 선이 따라옴
- **실행 취소/다시 실행**: 최대 100단계
- **자동 저장**, **보드 여러 개**(만들기·이름 바꾸기·복제·삭제·썸네일)
- **내보내기**: PNG 이미지(배경 포함 여부 선택), JSON 백업 / **불러오기**: JSON → 새 보드
- 라이트/다크 모드, 오프라인 사용, 홈 화면에 추가(PWA)

### 단축키 (PC)

| 키 | 기능 | 키 | 기능 |
|---|---|---|---|
| V | 선택 | Ctrl+Z | 실행 취소 |
| H | 화면 이동 | Ctrl+Shift+Z / Ctrl+Y | 다시 실행 |
| P | 펜 | Ctrl+C / V / D | 복사 / 붙여넣기 / 복제 |
| E | 지우개 | Delete | 삭제 |
| R / O | 사각형 / 원 | Ctrl+0 | 100%로 맞추기 |
| T | 텍스트 | Shift+1 | 전체 보기 |
| N | 포스트잇 | Space+드래그 | 화면 이동 |
| C | 연결선 | ? | 단축키 도움말 |

### 휴대폰·태블릿에서

- 빈 곳을 한 손가락으로 끌면 화면 이동, 두 손가락으로 벌리거나 오므리면 확대·축소
- 텍스트·포스트잇은 두 번 탭해서 수정
- 속성 시트는 그림을 그리기 시작하면 내려가요. 쓰고 있는 도구 버튼을 한 번 더 누르면 다시 올라와요
- 버튼을 길게 누르면 이름이 나와요

## 2. GitHub Pages에 올리는 방법 (처음 해보는 분용)

1. **GitHub 가입·로그인**: https://github.com 에서 계정을 만들고 로그인합니다.
2. **저장소 만들기**: 오른쪽 위 **+** → **New repository**를 누릅니다.
   - Repository name: 예) `whiteboard`
   - **Public**을 선택합니다. (무료 계정은 Public 저장소만 Pages를 쓸 수 있어요.)
   - **Create repository**를 누릅니다.
3. **파일 올리기**: 새 저장소 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 누릅니다.
   - 내려받은 zip 파일의 **압축을 푼 뒤**, 그 안의 파일과 폴더 전부(`index.html`, `manifest.webmanifest`, `sw.js`, `icons` 폴더, `.nojekyll`, `README.md`)를 끌어다 놓습니다.
   - `icons` 폴더는 폴더째 끌어다 놓아야 폴더 구조가 유지돼요.
   - `.nojekyll`은 이름이 점(.)으로 시작해서 탐색기·Finder에서 안 보일 수 있어요. 보이지 않으면 저장소 화면에서 **Add file → Create new file**을 누르고 이름을 `.nojekyll`로 적어 빈 파일로 저장하면 됩니다.
   - 아래 **Commit changes**를 누릅니다.
4. **Pages 켜기**: 저장소의 **Settings** → 왼쪽 메뉴 **Pages**
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`, 폴더는 `/ (root)` 선택 → **Save**
5. **접속 주소 확인**: 1~2분쯤 지나면 같은 화면 위쪽에 주소가 나타납니다.
   - 예) `https://아이디.github.io/whiteboard/`
   - 이 주소로 들어가면 바로 쓸 수 있어요.

> **업데이트할 때**: 파일을 다시 올린 뒤 `sw.js` 맨 위의 `CACHE_VERSION` 값(예: `v1.0.0` → `v1.0.1`)도 바꿔 주세요. 그래야 이미 접속했던 기기에도 새 버전이 반영됩니다. 새 버전은 앱을 한두 번 새로 열면 적용돼요.

## 3. 휴대폰 홈 화면에 추가하기

**iPhone (Safari)**
1. Safari로 위 주소에 접속합니다.
2. 아래쪽 **공유 버튼**(네모에 위쪽 화살표)을 누릅니다.
3. **홈 화면에 추가**를 누르고, 오른쪽 위 **추가**를 누릅니다.

**Android (Chrome)**
1. Chrome으로 위 주소에 접속합니다.
2. 오른쪽 위 **⋮** 메뉴 → **홈 화면에 추가**(또는 **앱 설치**)를 누릅니다.
3. **설치/추가**를 누릅니다.

홈 화면 아이콘으로 열면 주소창 없이 앱처럼 열리고, 한 번 연 뒤에는 인터넷 없이도 열립니다.

## 4. 데이터 저장에 대해 (꼭 읽어 주세요)

- 그린 내용은 **지금 쓰는 기기의, 지금 쓰는 브라우저 안에만**(localStorage) 저장됩니다. 서버로 보내지 않아요.
- 그래서 **다른 기기나 다른 브라우저에서는 보이지 않고**, 브라우저의 "사이트 데이터 삭제"를 하면 함께 지워집니다.
- iPhone Safari에서는 홈 화면 앱과 Safari 탭의 저장 공간이 서로 다를 수 있어요.
- 브라우저 저장 공간은 보통 5MB 정도라서, 그림이 아주 많으면 "저장 실패"가 뜰 수 있어요. 이때는 JSON으로 백업한 뒤 안 쓰는 보드를 지워 주세요.

**JSON 백업 방법**
1. 오른쪽 위 **내보내기(↓)** 버튼 → **JSON 파일로 백업**을 누르면 `.json` 파일이 내려받아져요.
2. 다른 기기에서 복원하려면: **내보내기(↓)** → **JSON 파일 불러오기**(또는 보드 목록의 **JSON 불러오기**)에서 그 파일을 고르면 **새 보드**로 들어옵니다.

## 6. 알려진 한계

- 보드 데이터는 기기 간에 자동으로 동기화되지 않습니다(JSON 백업으로 옮기기).
- 같은 보드를 여러 탭에서 동시에 고치면 마지막에 저장한 탭의 내용이 남습니다.
- PNG 내보내기는 항상 밝은 테마 색으로 만들어집니다.
- 지우개는 닿은 요소를 통째로 지우는 "획 지우개"입니다(부분 지우기 없음).
- 이미지 붙여넣기, 도형 회전, 공동 편집은 지원하지 않습니다.
